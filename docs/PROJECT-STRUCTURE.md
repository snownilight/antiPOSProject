# 專案架構說明 (Project Structure)

## 1. 系統架構 (System Architecture)
- **架構模式**：前後端分離 (Decoupled Architecture)

## 2. 後端技術棧 (Backend Tech Stack)
- **程式語言**：Java 21
- **JDK 發行版**：Eclipse Adoptium (Temurin)
- **主要框架**：Spring Boot 3
- **建置工具**：Maven

## 3. 前端技術棧 (Frontend Tech Stack)
- **UI/CSS 框架**：Bootstrap
- **前端框架**：React
